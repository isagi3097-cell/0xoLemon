# CORS, Lua catalog and GSE generator repair — 2026-09-04

## Confirmed causes

- Production rejected `Origin: http://localhost:14201` with HTTP 500 while the same catalog requests without Origin succeeded. Web-only `WEB_ALLOWED_ORIGINS` was used globally.
- Global 100 requests / 15 minutes limiting preceded CORS. Desktop logs also contained Lua catalog HTTP 429 fallback.
- `.gitignore` rule `*.py[cod]` excluded frozen Python `.pyd` native modules, including `Cryptodome/Hash/_MD5.pyd`; `*.zip` excluded `base_library.zip`. Local resources were therefore not representative of a clean checkout.
- Tauri resources did not include GSE/core. Release code could look back into the build machine's source directory.
- Setup silently retried a failed full generator with `-skip_ach`, and could retry a failed original core using a different Rust implementation.
- The supplied GSE_UC service does **not** use the anonymous full achievement-owner scan as its primary workflow. It calls the generator with `skip_achievements=True` and then obtains mandatory achievement/stat schemas, translations and artwork from Steam Web API. The launcher's full-first/retry workflow was not equivalent.

## Implemented behavior

- Desktop API CORS is separate from web cookie/session origins. Unknown origins return 403. Denials/preflights do not spend application quotas; catalog reads and writes have separate budgets. Cookie-session origin guards remain unchanged.
- Lua catalog responses carry `catalogSource` and `fallbackReason`; UI warns about limited fallback catalogs and supports retry from the first full-catalog page. Health polling no longer spends catalog quota. Cold-start request allowance is 65 seconds.
- Narrow tracking exceptions restore runtime native modules/archives/component metadata. Bundle patterns exclude OAuth secrets, local updates, generated output and logs. A manifest/hash and Git-ignore preflight checks 1,419 GSE/generator resource files.
- Existing customized avatar assets and restored canonical sounds are explicitly pinned in `launcher-asset-overrides.json`; these are not new binary changes or reproducible-upstream provenance claims.
- Core is rebuilt as part of packaging. Release resource discovery no longer falls through to a developer checkout.
- Setup now uses the supplied GSE_UC workflow from the outset: generator configuration plus mandatory Steam Web API metadata. Shared `generate_complete_settings` is used by both production setup and the frozen-core preview. Missing required IDs, translations or artwork stop in staging; no failure selects a reduced workflow or a second setup pipeline.
- Generator launches isolate inherited Python/PyInstaller environment and Windows DLL search state. See [PyInstaller external program guidance](https://pyinstaller.org/en/stable/common-issues-and-pitfalls.html#launching-external-programs-from-the-frozen-application).
- Generator output is per-run under `downloading`; no prior output tree is deleted or reused. `-rel_out` changes the destination. `-def1`, `-anon`, `-skip_ach` match the supplied service's generator stage; achievement generation is mandatory through Steam Web API afterward. No cleanup flag is generated or executed.
- Canonical JSON/controller/artwork/language/depot files are verified byte-for-byte after mirroring. Explicit zero-valued overlay preferences are preserved.
- Concurrent localization responses are serialized in requested-language order so identical metadata does not acquire different hashes solely from network completion order. Failure no longer emits a misleading subsequent deployment-preparation progress event.

## Deployment boundary

No commit, push, Render deployment, user game mutation or recursive directory cleanup was performed. Include the newly unignored GSE runtime files when reviewing/committing this change; committing code alone reintroduces the clean-checkout failure. Render must receive the backend change, and users need a rebuilt launcher for desktop/GSE changes. Do not open CORS to `*` or add desktop origins to the cookie-session allowlist as a workaround.

Imported component source provenance, redistribution licenses, real-game overlay/achievement acceptance and release installation remain independent gates. Local compile/test evidence does not make those gates verified.
